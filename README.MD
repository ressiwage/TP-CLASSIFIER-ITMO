# ТП помощник

## TL;DR:
MVP системы для обработки юзерских тикетов в техподдержку с использованием классификатора критичности и RAG

требования:
- python 3.12.3
- linux/wsl2

запуск: 
```sh
cd code/POC
pip install reqs.txt
uvicorn main:app --reload
# открыть браузер на http://127.0.0.1:8000
```
за мат извините, не было времени вырезать

## Что делает
решение на лету оценивает критичность запроса ТП и в зависимости от этого передаёт тикет оператору, выдаёт готовое решение либо отправляет RAG-запрос в Claude Sonnet 5 (API)
